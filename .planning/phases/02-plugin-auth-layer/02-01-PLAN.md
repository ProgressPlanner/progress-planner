<objective>
Extract Bearer token + HMAC auth methods from Remote_Status into a shared Remote_Base abstract class so all `/remote/` endpoints inherit authentication.

Purpose: Phase 3 adds POST endpoints under `/remote/` that need the same auth. Currently `check_permission`, `extract_bearer_token`, and `verify_signature` are private on Remote_Status. Moving them to a shared base makes them available to all remote controllers.
Output: New `Remote_Base` class extending `Rest\Base`, `Remote_Status` updated to extend `Remote_Base`.
</objective>
